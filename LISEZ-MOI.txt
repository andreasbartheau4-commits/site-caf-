SITE MAISON BARTHEAU CAFÉ — MODE D'EMPLOI

CE QUE CONTIENT LE DOSSIER
- index.html ............ le site : accueil, commander, professionnels, questions, contact, mon compte
- pro.html .............. l'espace professionnel complet (accès par code)
- cgv.html, mentions-legales.html, confidentialite.html ... pages légales
- 404.html .............. page « introuvable »
- assets/config.js ...... VOS COORDONNÉES ET LE PAIEMENT
- assets/produits.js .... VOS CAFÉS : noms, descriptions, photos, prix
- assets/catalogue.js, assets/shop.js ... « Nos cafés », panier et paiement (ne pas modifier)
- api/cle-stripe.php .... VOTRE CLÉ SECRÈTE STRIPE (à remplir, ne jamais la partager)
- api/checkout.php, api/lib.php ... ouverture du paiement Stripe (ne pas modifier)
- MISE-EN-LIGNE-IONOS.txt ... le guide pour mettre le site en ligne chez IONOS
- assets/style.css ...... le design (couleurs en haut du fichier : --accent, --bg)
- assets/site.js ........ menu mobile, thème clair/sombre, coordonnées
- assets/minicart.js .... le petit panier de la barre du haut (ne pas modifier)
- assets/fonts/ ......... les polices, hébergées sur le site (aucun lien avec Google)
- assets/img/ ........... icônes, logo détouré, image de partage réseaux sociaux
- logo.jpg .............. le logo
- robots.txt, sitemap.xml, site.webmanifest, .htaccess ... fichiers techniques (référencement, HTTPS, hébergement IONOS)

VOIR LE SITE
- Double-cliquez sur index.html : il s'ouvre dans votre navigateur.

AVANT LA MISE EN LIGNE (obligatoire en France)
1. Ouvrez assets/config.js et remplissez : nom, SIRET, adresse, téléphone,
   hébergeur, médiateur de la consommation (et Instagram si vous en avez un).
   Tant qu'un champ est vide, le site affiche « à compléter ».
2. Faites relire cgv.html par un professionnel si possible (modèle sérieux, mais générique).
3. Quand vous avez votre nom de domaine : remplacez maisonbartheau.com dans robots.txt
   et sitemap.xml.

METTRE EN LIGNE
- Hébergement : IONOS (offre « Hébergement web » avec PHP). Suivez MISE-EN-LIGNE-IONOS.txt.

NOS CAFÉS (ajouter photos et descriptions)
- Ouvrez assets/produits.js : chaque bloc { ... } est un café.
- Photos : déposez-les dans assets/img/produits/ puis écrivez leur chemin dans « image ».
- Mettez disponible: true pour qu'un café puisse être commandé ; false l'affiche « Bientôt disponible ».
- Les champs origine, torréfaction, notes, intensité n'apparaissent que si vous les remplissez.
- TARIFS ACTUELS : sachet 250 g 11,90 € · duo 2 × 250 g 22 € · kilo (4 × 250 g) 39 €.
  Livraison offerte dès 35 € (assets/config.js, LIVRAISON.offerteDes).
- Pour changer un tarif : dans assets/produits.js, ligne « formats » du café (prix: ...).
  Le site ET le paiement Stripe suivent automatiquement (api/checkout.php relit ce fichier).
- Les mentions « 11,90 € » de la page d'accueil (pastille, formule « Le sachet », barre mobile)
  sont écrites dans index.html : pensez à les modifier aussi si vous changez le prix.

BOUTIQUE EN LIGNE : PAIEMENT DIRECT (carte bancaire, Apple Pay, Google Pay)
- Tout est expliqué pas à pas dans MISE-EN-LIGNE-IONOS.txt.
- Le paiement se fait sur la page sécurisée de Stripe ; le site n'encaisse rien lui-même
  et ne voit jamais les cartes. Coût : environ 1,5 % + 0,25 € par paiement par carte
  européenne, sans abonnement. Samsung Pay n'est pas proposé par Stripe en France :
  les téléphones Samsung paient avec Google Pay ou la carte.
- La clé secrète Stripe va UNIQUEMENT dans api/cle-stripe.php.
- Le stock n'est pas géré en ligne : quand un café est épuisé, mettez
  disponible: false dans assets/produits.js.
- Fidélité : quand un client réclame son sachet offert, créez un « code promo » dans
  Stripe (Produits > Coupons) et envoyez-le-lui ; il le saisit au paiement.
- Remboursement : depuis la commande dans Stripe, bouton « Rembourser ».
- Sans clé Stripe (ou en ouvrant index.html sur votre ordinateur), le panier propose
  automatiquement d'envoyer la commande par e-mail : rien n'est jamais bloqué.

À NE PAS MODIFIER À LA MAIN
- Le tarif professionnel et les codes d'accès sont chiffrés ("var VAULT" dans index.html et pro.html).
  Pour les changer, il faut les régénérer.

COOKIES ET BANDEAU « ACCEPTER / REFUSER »
- Le site n'en a pas besoin aujourd'hui : il ne dépose aucun cookie publicitaire,
  aucune mesure d'audience, aucun traceur, et ne contacte aucun service tiers
  (même les polices sont hébergées sur le site). Ce qu'il garde dans le navigateur
  (panier, compte, thème) est strictement nécessaire : la CNIL l'exempte de consentement.
- Le paiement se fait sur la page de Stripe : ses éventuels cookies sont gérés par Stripe.
- SI VOUS AJOUTEZ un jour Google Analytics, un pixel Facebook/Meta, Hotjar, une vidéo
  YouTube intégrée, un widget Instagram... un bandeau de consentement devient OBLIGATOIRE
  avant de les activer. Demandez-le : il faut l'installer en même temps que l'outil.
