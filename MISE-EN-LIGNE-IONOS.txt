METTRE LE SITE EN LIGNE CHEZ IONOS · www.maisonbartheau.com
====================================================================
Durée : environ 30 minutes, puis jusqu'à quelques heures pour le cadenas HTTPS.


ÉTAPE 0 · VÉRIFIER VOTRE OFFRE IONOS (important)
--------------------------------------------------------------------
Il faut une offre « HÉBERGEMENT WEB » (Web Hosting : Starter, Essential, Plus…),
qui permet de déposer ses propres fichiers et fait tourner PHP.
  ✓ Dans votre espace IONOS, le menu doit montrer « Hébergement » ou « Webspace ».
  ✗ Un simple « Domaine » ne suffit pas.
  ✗ « Créateur de site / MyWebsite » ne permet pas de déposer ce site.
Si vous n'avez que le domaine : Menu > « Hébergement » > ajoutez une offre
d'hébergement web (l'entrée de gamme suffit).


ÉTAPE 1 · DÉPOSER LES FICHIERS
--------------------------------------------------------------------
1. Décompressez le zip du site sur votre ordinateur.
2. IONOS > Menu > Hébergement > « Webspace Explorer » (gestionnaire de fichiers).
3. Ouvrez le dossier racine (souvent « / » ou le dossier proposé pour le domaine).
4. Déposez TOUT le contenu du dossier du site, en gardant les sous-dossiers :
     index.html, pro.html, cgv.html, mentions-legales.html, confidentialite.html,
     404.html, logo.jpg, robots.txt, sitemap.xml, site.webmanifest,
     le dossier assets/, le dossier api/,
     et les fichiers « .htaccess » (à la racine ET dans api/).
   ⚠ Les fichiers qui commencent par un point (.htaccess) sont cachés sur Mac :
     dans le Finder, faites Cmd + Maj + . (point) pour les voir.
   Alternative : FileZilla en SFTP (identifiants dans Hébergement > « SFTP & SSH »).
5. Version de PHP : Hébergement > « PHP » > choisissez 8.1 ou plus récent.


ÉTAPE 2 · RELIER LE DOMAINE ET ACTIVER LE CADENAS
--------------------------------------------------------------------
1. IONOS > « Domaines & SSL » > maisonbartheau.com > « Utilisation du domaine »
   (ou « Destination ») > « Webspace » > choisissez le dossier où vous avez déposé
   les fichiers. Faites la même chose pour www.maisonbartheau.com.
2. Toujours dans « Domaines & SSL » : activez le certificat SSL (inclus dans l'offre)
   et attribuez-le à maisonbartheau.com ET www.maisonbartheau.com.
3. Ne touchez pas aux réglages e-mail (MX) si vous avez une adresse IONOS.
4. Après quelques minutes à quelques heures : https://www.maisonbartheau.com
   affiche le site avec un cadenas. Le site redirige tout seul vers https et www.


ÉTAPE 3 · ACTIVER LE PAIEMENT (carte bancaire, Apple Pay, Google Pay)
--------------------------------------------------------------------
1. Créez votre compte sur https://dashboard.stripe.com/register et activez-le
   (identité, SIRET 133 098 566 00010, IBAN où recevoir l'argent).
2. Stripe > Paramètres > Moyens de paiement : Cartes, Apple Pay, Google Pay activés.
3. Stripe > Paramètres > E-mails clients : activez « Paiements réussis » (reçu au client).
4. Stripe > Paramètres > Notifications (votre profil) : cochez les e-mails
   « Paiements réussis » pour être prévenu de CHAQUE commande.
5. Stripe > Développeurs > Clés API : copiez la « Clé secrète »
   (sk_test_... pour essayer d'abord).
6. Dans le Webspace Explorer, ouvrez api/cle-stripe.php, collez la clé entre
   les guillemets de 'secret_key' => '', enregistrez.
7. Frais d'envoi : ouvrez assets/config.js, remplacez fraisEnvoi: null par votre
   tarif (ex. fraisEnvoi: 6.90,). Tant qu'il reste à null, seul le retrait en main
   propre se paie en ligne, et la livraison se commande par e-mail.

Tant que la clé est vide, le site reste utilisable : le panier propose
automatiquement d'envoyer la commande par e-mail.


ÉTAPE 4 · TESTER PUIS VENDRE POUR DE VRAI
--------------------------------------------------------------------
1. Avec la clé sk_test_ : ajoutez un café au panier > « Payer ».
   Carte de test : 4242 4242 4242 4242, une date future, code 123.
2. Vous devez arriver sur la page « Merci », et voir la commande dans Stripe
   (mode test) avec le détail : format, mouture, machine, adresse.
3. Remplacez la clé par sk_live_... dans api/cle-stripe.php : c'est en vente.


AU QUOTIDIEN
--------------------------------------------------------------------
- Chaque commande : e-mail de Stripe + appli Stripe (iPhone / Android) avec
  le détail à préparer (cafés, format, mouture, machine, adresse, téléphone).
- Stock : géré par vous. Un café épuisé ? Dans assets/produits.js, mettez
  disponible: false (il s'affiche « Bientôt disponible »), puis déposez le fichier.
- Modifier le site : modifiez le fichier sur votre ordinateur, puis déposez-le
  à nouveau au même endroit dans le Webspace Explorer (il remplace l'ancien).
- Google : https://search.google.com/search-console > ajoutez maisonbartheau.com
  > envoyez https://www.maisonbartheau.com/sitemap.xml pour être trouvé plus vite.
